# 🔥 День 5. Версии моделей через Groq API (Week 1, Task 5)

Решение практической задачи 5-го дня AI Advent Challenge, посвящённой исследованию и сравнительному анализу трёх классов моделей на аппаратной платформе **Groq** с использованием официального **Groq API** и архитектуры LPU (Language Processing Unit).

В качестве бенчмарка выбрана многошаговая логико-арифметическая задача с проверкой строгого следования формату **JSON** (Instruction Following) в детерминированном режиме (`temperature = 0.0`).

---

## 🎯 Исследуемые модели

1. 👉 **Слабая модель (Weak):** `openai/gpt-oss-20b` (~20B параметров)
2. 👉 **Средняя модель (Medium):** `qwen/qwen3.6-27b` (~27B параметров)
3. 👉 **Сильная модель (Strong):** `openai/gpt-oss-120b` (~120B параметров)

---

## 📝 Тестовый промпт

```text
У меня в корзине было 4 яблока и 2 апельсина. Я съел одно яблоко, затем разрезал один апельсин пополам и отдал половину другу. Одно яблоко я обменял на две груши. Сколько у меня сейчас целых фруктов, сколько половинок, и какие именно это фрукты?

Твой ответ должен быть выведен строго в формате JSON по следующему шаблону (не пиши никакой текст до или после JSON):
{
"общее_число_целых": число,
"общее_число_половинок": число,
"какие_целые": {
"название_фрукта_1": количество,
"название_фрукта_2": количество,
"название_фрукта_3": количество
},
"какие_половинки": {
"название_фрукта": количество
},
"пояснение": "краткое объяснение расчетов на 1 предложение"
}
```

---

## 📐 Замеряемые метрики

- ⏱️ **Время ответа (Latency):** общее время от отправки HTTP-запроса до получения финального ответа (в секундах).
- 🔢 **Количество токенов:**
  - **Prompt Tokens** (входной контекст задачи)
  - **Completion Tokens** (сгенерированный ответ JSON)
  - **Total Tokens** (суммарный объём)
- ⚡ **Скорость генерации (Throughput):** число токенов в секунду (`completion_tokens / elapsed_time`) на LPU-процессорах Groq.

---

## 🔍 Сравнительный анализ

- 🧠 **Качество ответов и логика (Instruction Following & Reasoning):**
  - **Точность расчетов:** корректность многошагового вычисления (эталон: 5 целых фруктов, 1 половинка).
  - **Валидность JSON:** строгая валидность структуры, отсутствие синтаксических ошибок (проверяется через `json.loads`).
  - **Соблюдение ограничений:** отсутствие пояснительного текста или Markdown-блоков (` ```json `) до или после JSON.
- 🚀 **Скорость:** сравнение производительности Groq LPU на моделях 20B, 27B и 120B.
- 💡 **Ресурсоёмкость:** сравнение объёма токенов и лаконичности ответов.

## 🚀 Быстрый старт

### 1. Настройка переменных окружения

В папке `week1/task5/` настройте файл `.env`:
```bash
# Windows PowerShell / CMD:
copy .env.example .env
```

Внутри `.env` укажите ваш API-ключ Groq:
```env
# Получить бесплатный ключ: https://console.groq.com/keys
GROQ_API_KEY=gsk_ваш_ключ_groq

MODEL_WEAK=openai/gpt-oss-20b
MODEL_MEDIUM=qwen/qwen3.6-27b
MODEL_STRONG=openai/gpt-oss-120b
```

### 2. Запуск эксперимента

Запуск со стандартными моделями и `temperature = 0.0`:
```bash
python main.py
```

Запуск с переопределением моделей через CLI:
```bash
python main.py --weak "openai/gpt-oss-20b" --medium "qwen/qwen3.6-27b" --strong "openai/gpt-oss-120b"
```

Справка по всем опциям:
```bash
python main.py --help
```
