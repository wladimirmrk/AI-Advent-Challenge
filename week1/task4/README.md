## ⚙️ Что такое параметр `temperature` под капотом?

В архитектуре Transformer модель вычисляет логиты (сырые числовые баллы) для каждого токена в словаре. Для преобразования логитов в вероятности используется функция **Softmax** с делением на температуру $T$:

$$P(w_i) = \frac{e^{z_i / T}}{\sum_{j} e^{z_j / T}}$$

- При **$T \to 0$ (или $T = 0$)**: распределение вероятностей стягивается в дельта-функцию Дирака вокруг токена с наибольшим логитом (argmax / greedy decoding). Модель выбирает только самый вероятный токен. Ответ детерминирован и повторяем.
- При **$T = 0.7$**: распределение вероятностей слегка сглажено, сохраняя доминирование логичных вариантов, но допуская разумный выбор менее очевидных токенов.
- При **$T > 1.0$ (например, $1.2$)**: распределение уплощается (энтропия растёт), вероятности редких и низковероятных токенов возрастают. Модель делает неожиданные, иногда причудливые или хаотичные выборы.

## 🚀 Быстрый старт

### 1. Установка зависимостей
Убедитесь, что установлен Python 3.8+ и перейдите в папку задачи:
```bash
cd week1/task4
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```
Откройте файл `.env` и укажите ваш API-ключ OpenRouter:
```env
OPENROUTER_API_KEY=sk-or-v1-ваш-ключ-openrouter
OPENROUTER_MODEL=minimax/minimax-m3:free
```

### 3. Запуск эксперимента
Запустите скрипт со стандартным творческим запросом:
```bash
python main.py
```

Или укажите собственный промпт и модель:
```bash
python main.py --prompt "Объясни квантовую запутанность для пятилетнего ребенка" --model "openai/gpt-4o-mini"
```

После выполнения скрипт:
1. Выведет ответы для каждого значения температуры в терминал.
2. Распечатает подробную аналитику и выводы.
3. Автоматически сохранит полученные результаты и отчёт в файл `results.md`.

## 📊 Результаты сравнения: «Придумай 3 необычных названия и слогана для кофейни в космосе»

Ниже приведены реальные примеры генерации модели при разных температурах:

### 🔹 Temperature = 0.0 (Детерминированный, строгий)
```text
1. Название: "Гравитация вкуса"
   Слоган: "Притяжение, которому невозможно сопротивляться."

2. Название: "Орбитальный эспрессо"
   Слоган: "Твой заряд бодрости на скорости 28 000 км/ч."

3. Название: "Нулевая чашка"
   Слоган: "Наслаждайся кофе в невесомости."
```
> **Характеристика:** Чёткое выполнение формата, логичные и ожидаемые образы («орбитальный», «невесомость», «притяжение»). Высокая точность, но клишированные идеи.

---

### 🔹 Temperature = 0.7 (Сбалансированный)
```text
1. Название: "Event Horizon Brew" (Горизонт событий)
   Слоган: "Кофе настолько темный, что даже свет не сбежит от его аромата."

2. Название: "Лунная пенка"
   Слоган: "Сделай один маленький глоток для человека, один гигантский заряд для экипажа."

3. Название: "Звёздная пыль & Какао"
   Слоган: "Заправляй свой внутренний шаттл правильным топливом."
```
> **Характеристика:** Живой язык, остроумные отсылки (цитата Нила Армстронга, астрофизические термины), отличный баланс между оригинальностью и коммерческой привлекательностью.

---

### 🔹 Temperature = 1.2 (Творческий, высокая энтропия)
```text
1. Название: "Сингулярность в турке: Кварковый пар"
   Слоган: "Искривляем пространство-время ради одного пенного каскада под вой солнечного ветра!"

2. Название: "Тахионный эликсир №9"
   Слоган: "Ты выпил его завтра, а проснёшься ещё вчера на кольцах Сатурна."

3. Название: "Неоновый Небулоид"
   Слоган: "Глотай кометный хвост со взбитыми сливками из антиматерии!"
```
> **Характеристика:** Максимальный полёт фантазии, дерзкие и эксцентричные метафоры, сюрреалистичный юмор. Идеи выбиваются за рамки обыденного восприятия.

## 🎯 Рекомендации: для каких задач подходит каждая настройка

### 🟢 `temperature = 0.0` (Аналитика, Код, Факты)
* **Генерация и отладка программного кода** (Python, SQL, TypeScript)
* **Извлечение структурированных данных** (парсинг сущностей в JSON/YAML)
* **Математика, статистика и логические задачи**
* **Классификация текстов и модерация контента**
* **Корпоративные RAG-системы** (ответы строго по регламентам и базам знаний без «отсебятины»)

### 🟡 `temperature = 0.7` (Повседневные задачи, Контент, Диалог)
* **Интеллектуальные чат-боты и персональные ассистенты**
* **Копирайтинг, статьи для блогов, эссе, деловая переписка**
* **Суммаризация и рерайтинг материалов** с сохранением естественности речи
* **Перевод текстов** с адаптацией культурных и языковых нюансов
* **Образовательные объяснения** концепций простыми словами

### 🔴 `temperature = 1.2` (Брейншторминг, Творчество, Нестандартные идеи)
* **Нейминг и разработка слоганов** для брендов и стартапов
* **Художественная литература, сценарии, фэнтези/sci-fi рассказы, стихи**
* **Создание диалогов игровых NPC и генерация квестов**
* **Поиск нестандартных гипотез** в R&D и исследовательских проектах
* **Преодоление «страха чистого листа»** (генерация сырого пула необычных мыслей)
