# Task 1: Минимальный клиент для OpenRouter LLM API

Минимальный CLI-скрипт на Python для отправки запросов к языковым моделям через API OpenRouter и вывода ответов в консоль.

## Возможности
- 💬 **Интерактивный диалог в консоли**: ввод вопросов в цикле без перезапуска скрипта.
- 🌐 **Прямые HTTP-запросы**: реализация через библиотеку `requests` без громоздких SDK.
- 🔒 **Безопасное хранение ключей**: API-ключ загружается из файла `.env` (который добавлен в `.gitignore` и защищен от коммитов).
- ⚙️ **Гибкая конфигурация**: модель по умолчанию `minimax/minimax-m3:free`, можно переопределить через переменную `OPENROUTER_MODEL`.
- 🛡️ **Надежная обработка ошибок**: информативные сообщения при проблемах с сетью, некорректном ключе или лимитах API.

---

## Быстрый старт

### 1. Установка зависимостей
Рекомендуется использовать виртуальное окружение:

```bash
# Переход в папку задания
cd week1/task1

# Создание и активация виртуального окружения (опционально)
python -m venv venv
# На Windows:
venv\Scripts\activate
# На Linux / macOS:
# source venv/bin/activate

# Установка необходимых пакетов
pip install -r requirements.txt
```

### 2. Настройка API-ключа
1. Скопируйте файл `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   # Или в Windows PowerShell:
   Copy-Item .env.example .env
   ```
2. Откройте файл `.env` и укажите ваш ключ от OpenRouter:
   ```env
   OPENROUTER_API_KEY=sk-or-v1-ваш_настоящий_ключ
   OPENROUTER_MODEL=minimax/minimax-m3:free
   ```
   > ⚠️ **Важно:** Ни в коем случае не публикуйте файл `.env` в публичные репозитории. Файл `.env` уже внесен в корневой `.gitignore`.

### 3. Запуск скрипта
```bash
python main.py
```

После запуска введите ваш вопрос в строке `Вы: ` и нажмите `Enter`. Для выхода введите `exit` или `quit`.
